# Career Companion 产品规格

这份目录回答什么问题：产品是什么，12 份规格各管什么、冲突时以谁为准，哪些已经定了、哪些还要定，Codex 和 Claude 应该怎么用这些文档。

结论：

- 产品是面向在美中国留学生（STEM 硕士、找 new grad 岗位）的陪伴型求职 Agent：每位用户有一个专属的主理人（系统生成性格，用户起名），加一支按需入场的小组（前辈、投递官、面试官，之后是规划师、技能教练、人脉官），共享同一份关于用户的记忆。
- P0 只做 Web，网页本身就是完整的小组；手机靠手机网页（可安装）和 Discord 私信，原生 App 以后再做。
- 浏览器插件保留，是投递效率的核心；授权在小组对话里一次问清，最终提交永远由用户本人点。
- 实现顺序以 `09-implementation-roadmap.md` 为准，分期以 `07-first-cohort-mvp.md` 为准。

## 一页纸

| 方面 | 决定 |
|---|---|
| 用户 | 在美中国留学生、STEM 硕士、找 new grad 岗位（SWE、DS、MLE、数据分析等）。第一批是真实用户，不是 demo。 |
| 核心关系 | 用户只和主理人建立关系；专家由主理人拉进同一条小组对话，也可以 @ 召唤；所有队员共享同一份记忆。不做七个各自独立的机器人。 |
| 队伍 | 主理人（用户起名，印章与墨色由生成系统决定）；前辈「前」；投递官「投」；面试官「面」；规划师「规」；技能教练「教」；人脉官「脉」。「导师」一词只用于蔓藤真人导师。 |
| 父母和朋友 | 不模拟，帮用户连接真实的人：给爸妈的周报（内容完全由用户决定）、同期伙伴、蔓藤真人导师。 |
| 五个界面 | 今天、对话、待确认、旅程、我。 |
| 调性 | 小组为主体；「来信」是群里的信件卡片（第一封信、晨报、被拒之后、Offer、年鉴、导师评阅；给爸妈的周报是待确认对象，不是群里的信）；「指挥台」是任务卡片、宽屏侧栏和旅程页。 |
| 对外动作 | 要发给别人的消息和材料，都先进待确认；表单里哪些项可以替你做，由你在小组对话里逐项确认（见 11）；最终提交永远由你本人点。 |
| 插件 | 投在小组对话里分组问清哪些项可以替你勾（不预选、不推荐），点确认卡才生效；之后全部自动，没授权的项在浮层标「留给你」、攒到小组里补问。 |
| 安全 | 每条用户消息先做安全分级；危机回应由服务端模板直接生成，不依赖模型、不受费用上限和故障影响。身份相关数字只来自经过审核的配置，是信息与提醒，不是法律意见。 |
| 不编造 | 对外材料与面试反馈不得引入用户已确认资料以外的事实；工作授权、sponsorship、公民身份、EEO 类答案只从用户确认过的档案字段填入，否则显示「需要你自己回答」。 |
| 蔓藤 | 面经、题库、学员简历、导师方法论、规划师话术、AI 课程、导师网络、小企业内推、真人一对一（可售）。内推评估等法务审核后再开放（待确认第 1 项）。 |
| 声线 | 面试官全员一个固定声线（P0 逐回合朗读，P1-11 起实时语音）；主理人用「声音设计」预制声线池，按性格推荐；开源自托管作为每人独有声线的后续路线。不克隆任何真人声音。最终以盲测决定。 |

## 分期速览

以 `07-first-cohort-mvp.md` 为准，这里只列标题。

**P0：第一批 Web**（队伍只有主理人、前辈、投递官、面试官）

- P0-1 主理人实体与生成
- P0-2 安全分级、危机流程与 AI 透明
- P0-3 对话轮次服务与多发言者小组
- P0-4 五个界面与小组 UI
- P0-5 初见与第一封信（含邀请码与数据授权确认）
- P0-6 晨报、三件事与调度（含邮件提醒）
- P0-7 对外发出类待确认（简历版本、投递材料包、邮件草稿、外联消息）
- P0-8 可编辑的共享记忆
- P0-9 求职数据表
- P0-10 面试官最小版
- P0-11 蔓藤内容最小导入
- P0-12 真人入口最小版（意向登记，蔓藤线下撮合与收款）
- P0-13 质量评测与按用户费用上限
- P0-14 上线底座
- P0 期间同时做、不发布：插件安全修正（每站独立密码、外国岗位工作授权、LinkedIn 与 Indeed 本地禁用、资产清理）；开源声线 PoC（远程 3090）；MCP 外部数据来源

**P1a：紧随 Web 核心**

- P1-1 插件逐项授权并接通后端
- P1-2 Discord 私信机器人
- P1-3 身份时钟提醒
- P1-4 面经与作战简报
- P1-5 被拒之后的信与复盘

**P1b**

- P1-6 规划师 · P1-7 技能教练与课程目录 · P1-8 给爸妈的周报 · P1-9 组织共享知识库完整版 · P1-10 真人导师预约与交接 · P1-C 收费前 · P1-11 沉浸式实时面试 · P1-12 主理人声线 · P1-13 Offer 那天与落地 · P1-14 Web Push

**P2**

- 人脉官 · Discord 社区 · 同期伙伴 · 求职年鉴 · 批量预填（不含自动提交）· 连续语音对话与打断（评估）· 主理人自动微调 · 岗位筛选 · Capacitor 与 iOS · 自托管开源声线 · 短信、微信、Gmail 只读线索 · 日历只读（评估）

## 怎么用这些文档

- 实现产品功能前先读相关文档；发现文档与实现冲突，或想改变产品方向，先提出，不要自行改方向（见根目录 `AGENTS.md`）。
- Codex 按 09 的步骤推进，每一步对照验收标准；改动走 PR，不直接推 main。
- 各文档之间用「NN §x.y」交叉引用；同一主题只在它的权威文档里展开。
