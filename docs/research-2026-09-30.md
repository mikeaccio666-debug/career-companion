# 求职 AI 伙伴的聊天底座与竞品调研

调研日期：2026 年 9 月 30 日。本文依据官方项目、产品页面和帮助文档，回答怎样搭建自有品牌、电脑和手机都能使用的求职 AI 产品。未实际部署或试用，不将功能宣传视为效果证明。

**结论：已有成熟的通用聊天底座，不需要从零开发登录、聊天流和文件上传。建议正式产品从 Vercel Chatbot 加 AI SDK 起步，先做响应式网页；LibreChat 适合快速验证现成聊天体验。**这是选型建议。长期职业档案、岗位状态和持续行动仍需要自己设计。

## Muse 与 Dot 的参考含义

用户尚未提供产品链接。本文暂将 Muse 理解为 Meta Muse，将 Dot 优先理解为 OpenAI Dots；这只是本轮参考假设。

Meta 的 2026 年 9 月 8 日公告描述了 Muse 的记忆、主动计划、专用云端电脑和后台执行，并列出 iOS、Android 和网页入口。其设计文章还介绍主对话、侧对话、可编辑记忆和仅在有意义变化时主动通知的体验。[Meta 官方公告](https://about.fb.com/news/2026/09/introducing-muse-personal-ai-agent/)、[Muse 官方设计文章](https://introducing.muse.ai/)。

OpenAI Dots 官方文档描述了跨对话的笔记和偏好、云端电脑、后台任务，以及需要用户判断时带回结果。当前官方文档明确：支持相应更新后的手机 App，**不支持手机网页**，且正在逐步开放。这是可借鉴的产品体验，不能将其直接视为可部署到自有网站的白标系统。[Dots 官方文档](https://learn.chatgpt.com/docs/dots)。

另一个同名 Dot 是 New Computer 的历史陪伴产品；其当前官网已是停止运营公告。如果用户指的是它，后续应重新校准参考体验。[New Computer 官方公告](https://new.computer/)。

对求职产品的设计推断是：用户希望助手持续理解自己，把一个长期目标推进到具体行动，并能随时修改方向。这比每次重新解释背景更接近 Muse 和 Dots 的核心体验。

## 六种底座的实际区别

成品聊天应用适合迅速运行；代码模板适合重做产品交互；工作流平台适合编排后台任务；聊天组件只解决界面的一部分。它们的“一键部署”都不等于完成了求职产品。

## 网页与手机的建设路线

**建议先做响应式网页：同一个网址、账户、聊天和求职档案，电脑与手机同步使用。**这能先验证核心需求。下一阶段再加 PWA，也就是可添加到主屏幕的网页应用。原生 iOS 和 Android App 留到需求明确后考虑。PWA 可跨设备运行和安装，具体系统集成能力依赖浏览器及操作系统。[MDN PWA 文档](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps)。

建议手机验收关注：键盘弹出后输入框仍可见、长消息可读、文件选择和上传顺畅、退出再进入可恢复、手机和电脑共享同一档案。以上是拟定的验收标准，尚未测试。

如果要实现关闭网页后继续分析、按计划提醒或响应事件，建议由服务器的后台任务执行并保存结果，再通知用户。聊天前端负责显示过程；不能把长期执行寄托在手机浏览器一直开着。

OpenAI 的 Agents API 提供托管会话、任务编排、上下文压缩和执行环境，可在持续任务确实需要时评估；它是后台能力，不替代求职档案、账户和用户界面。[官方概览](https://developers.openai.com/api/docs/guides/agents-api/overview)。首版不必同时引入多个 Agent 平台。

**待验证的机会**是贯穿整个求职过程的伙伴体验：只维护一份可信职业档案，聊天可更新岗位和任务，结合申请反馈调整策略，用户低落时帮助选出一个可完成的行动。中文理解经历、英文表达材料也可能成为切口，但目标地区和语言需求尚未确定。

## 建议的首轮决策

1. 先做 Vercel Chatbot 模板的技术验证，围绕一个伙伴和一份求职档案开发；若先体验现成记忆与聊天，单独使用 LibreChat 做实验即可。
2. 用户提供一份真实简历和一个岗位描述，验证岗位诊断、申请准备、行动记录和复盘这一条闭环。
3. 比较应届、早期跳槽和转行者的真实需求，再选一个人群。当前没有证据支持直接锁定某一群体。
4. 成本按模型调用、文件处理、数据库、后台任务和通知分别记录，依据真实试用计算；本轮没有报价或费用承诺。

本轮尚未完成的验证包括：各项目稳定版本的实际手机质量、完整 PWA 支持、公开用户的计费与限额、跨用户数据隔离，以及具体招聘市场的岗位来源。当前没有运行产品、配置 API 密钥或发布服务。
