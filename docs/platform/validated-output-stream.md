# 对话输出的句级缓冲边界

依据产品 02 §3.4、03 §6.8 与 15 §3.1。`services/platform-api/src/validated-output-stream.ts` 把模型的文本分片转换成经调用方校验后才可继续处理的文本事件；它是学生轮次服务的组成准备，不是已经开放的学生聊天接口。

## 行为

句级模式使用固定英文 locale 的 ICU 句子分段（同时识别中文句末标点），保留最后一个分段等待后续字符，不以供应商分片边界切句。数字小数点、尾引号、跨分片的 Unicode 代理对、空格和 CRLF 都保留原文。很短的回复可能直到生成结束才放出，不能以此宣称满足首句延迟指标。信件、晨报、主动消息及交付物须选择 whole 模式，完整输出只审核一次，审核前不释放片段。

每个候选包含原文、此前实际释放的完整前缀、UTF-16 偏移和是否为结束尾段。服务端提供 reviewer，只有明确返回 approve 才产生 approved_text；block、review、异常、超时和不认识的返回值均停止。人格预览的 passed_rules 结果不能直接用来放行聊天。取消和超时会传递给 reviewer，迟到的批准不会补发。来源中断不把缓冲尾文当作完整句子发送。结果只带枚举和已释放字符/段数，不带被拦内容或内部错误正文。

总输出和未释放缓冲有明确上限，超过时停止，不为了清空缓冲而强行发送半句。调用方消费形成背压，不预取下一批模型内容；连续立即完成的分片，以及单个分片中的连续整句，每 32 次让出事件循环，避免空分片流饿死取消定时器和租约心跳。显式取消能中断等待中的来源或审核；不合作的 iterator.return 不阻塞停止操作，真实供应商传输仍必须使用同一轮次取消信号。模块本身不发网络请求、不调用模型、不记录内容日志。

## 接入边界

reviewer 必须由实际服务端轮次捕获，核本轮来源、发言者、敏感度、付费提及、身份数字和引用；模块没有以一个任意回调代替这些校验。候选前缀供跨句检查使用，结构化交付物与需要整体判断的内容不能按普通聊天分段。

真实账号授权、同步用户输入分级、房间/轮次租约、费用护栏、审核过的事实来源、输出的语义校验、一次重写、固定尾句、output_blocked 事件、持久化及 SSE 都仍由待接入的轮次服务负责。approved_text 不是执行许可或落库凭证；只有调用方确认实际写入及当前授权后才能向渠道发布。未接入这些环节之前，不能报告主理人已校验首句、转发卡校验误杀或完整端到端通过。

09 第 161 行的实测前置与当前 AGENTS.md 的禁止付费要求仍待产品负责人确认实施顺序。本改动没有绕过前置、启动轮次迁移、调用付费模型或改变产品文档。

## 验证范围

假 reviewer 测试覆盖分片背压、完整句等待、whole 模式、精确前缀/偏移、部分通过、审核失败、取消、超时、源中断、未知 verdict、配置捕获、控制字符、代理对和容量。300 组虚构分片组合用于检查文本往返保真，不是 300 段语义误杀评测。另把实际 ProviderAdapter 和 runAgentLoop 配上假 runtime，验证它们输出的原始 delta 经此边界后只释放获批部分；不模拟学生身份、费用或真实工具授权。

本分支最终验证：新增缓冲检查 20 项，与现有评测 probe / 输出投影一起运行共 35 项通过；实际共享 Agent 循环 23 项回归通过，合计 58 项、无跳过；platform-api 完整类型检查通过。300 组分片组合包含在上述一项测试中，不另加为测试数量。没有数据库迁移或 UI 改动，也没有付费调用、部署或修改主预览。
