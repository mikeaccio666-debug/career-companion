# 方法卡“看依据”：完整内容

依据产品 04 §3.4。学生在已有方法卡出处页点击“查看适用条件与完整方法”，读取同一来源、同一发布版本的方法。展示适用岗位、阶段、情境、准备条件、完整步骤与每步产出、停止条件、反例及何时需要真人帮助。

## 真实读取与权限

新增 `GET /org-knowledge/methods/:sourceId/:revision/:passageId`，沿用真实会话、窗口账号、学生身份、邮箱、条款、组织权益检查与 `org-knowledge` 突发限流。无请求正文、无额外查询参数；来源坐标必须规范，不能选择“最新”替代原版本。

- 完整展示需要有效许可中的 `retrieve` 与 `display_full`。只有模型处理或摘录权限时，返回固定的 403 `METHOD_FULL_NOT_ALLOWED`，网页保留已核对的摘录并解释全文尚未授权。
- 权益或许可撤回、过期、来源失效，使用既有拒绝／过期状态；网页在重新读取发现失效时清掉摘录及完整内容，不保留旧结果冒充当前可用内容。这不是实时撤权推送。
- 在同一有界事务内验证真实来源正文、结构化数据、发布证明及所有段落，写 `view_method_full` 访问日志；交付前再次核对权限与时间。取消不提交部分访问记录。
- 仍有效的历史方法版本可以展开，并显示历史版本说明。查看不更新用户计划。
- 只返回面向读者的闭合 DTO，不包含作者／审核员账号、许可凭据、工具声明、执行绑定或原始结构化 JSON。单卡内容最多 64 KiB。与技能读取共用 `orgMethodContent` 投影；模型用途与人类全文展示权限仍独立检查。

本接口是单来源阅读，不是批量导出。面经每日不同来源配额仍属于尚未接通的面经功能；本改动未擅自给方法卡设定新的产品额度，也不声称完成全部组织知识配额。

## 网页行为

完整内容只在用户展开后读取，收起即从状态与 DOM 中移除；再次展开重新请求。加载、权限不足和暂时不可用分别呈现固定文案，不展示后台错误正文。刷新出处会同时清空完整内容。

控制器捕获原引用与账号代际，隔离摘要和全文请求代际；收起、刷新、隐藏、离线、账号失效都会中止旧请求。即使传输忽略 abort，也不能发布晚到的内容；12 秒超时可结算。恢复联网或回到页面只重新读取摘录，全文仍由用户主动展开。正文不写入客户端持久化存储。

沿用现有设计变量与学生导航。展开按钮具有 aria-expanded/aria-controls，受控容器在收起时隐藏且不保留全文；内容采用文本节点、编号步骤和条件列表。没有“应用此方法”执行按钮、自动计划升级或新的付费建议。

## 验证

- 隔离 PostgreSQL：真实密码登录 HTTP → 当前账号 Web 客户端 → 控制器 → 来源服务；验证全文权限独立、历史版本、精确坐标、作者身份隔离、真实访问日志、撤回后清空、取消和损坏段落拒绝。
- 契约／控制器／React 静态渲染：闭合字段、冻结投影、禁止私密身份字段、反例必填、64 KiB 总上限、嵌套访问器与稀疏数组、请求代际、超时、忽略 abort、收起和账户失效、文本转义。
- Playwright：远端一次性数据库与实际 Fastify 服务、实际密码登录、实际 OrgSourcePage 和 StudentRoutes/StudentShell。确认 HTTP 200 展开、键盘收起／重开、断网清空及恢复后显式展开；真实服务撤销虚构许可后，再读得到 403 NOT_ENTITLED，旧正文消失；窗口账户失效后页面移除。
