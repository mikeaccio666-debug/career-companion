# 真人履约完成与一次性私人反馈

对应产品 04 §3.5、05 §2.15、06 §6.3 / §8.5 与 07 P0-12；前置为 [人工排期](mentor-scheduling.md)。

## 真实履约与付款

真实本机构 ops / org_admin 员工用原 `mentor-scheduling record` 私有 CLI，提交 action=complete、operationId、sessionId、expectedRevision=3、completedAt、本人 evidenceRef 与 confirmRecorded=true。原始履约依据须在实际上传表、文件字节和强 ETag 上有效；勾选不能替代文件，服务器不自行证明真人确实履约。只有 scheduled 能变为 completed；completedAt 不早于原约定结束时间，也不晚于当前数据库时间。继承原不可变操作回执 schemaVersion=3，保存实际运营/用户授权版本、文件版本、命令和新记录摘要。原操作重试只有一次效果，返回当前完成状态。审计失败、中止或身份失效不留下完成回执。

completed 不代表已付款、导师评阅、成长证据或真实质量验收；不联系会议平台、不录音、不生成导师评语。完成后不能再当作未完成预约取消；退款仍单独记录。原完整时段的历史占用保留，窗口已过去，不妨碍之后不重叠的时段。历史资料下线不改写已完成的服务。

真实线下收款可能晚于会后录入。completed 的收款记录沿实际历史报价与已确认履约凭据，不再要求已过去的时段或已撤下导师重新变成可售状态；仍要求真实运营授权、精确原报价金额、实际收款文件、显式保留政策、数据库时间和不可变账务回执。matched / scheduled 的新收款仍复核当前真实服务及未来时段。退款仍不以完成或取消自动执行。

## 反馈

073 新建 platform_mentor_ratings，每场服务最多一条本人决定：rate（1–5 整数、可选一句话，最多 500 字且无换行）或 skip。只存归属、操作编号、时间与密文；分数、文字、动作和本人授权版本全部在认证密文里。真实本人登录、学生身份、邮箱与现行法律同意、同一份真实 completed 意向是准备条件。意向状态与付款不随反馈改变，不产生共享记忆、成长证据或公开评价。

实际账号锁序列化同时提交，nonce 与场次绑定。相同原请求返回原回执，变更分数/文字/skip 或再次评分拒绝。跳过也持久化，下次打开不再次邀请。SQL 不可变触发器阻止更新/物理删除，账号或机构删除级联清除反馈；没有无密文摘要的默认评分或恢复空提示。上传的运营原始履约文件仍遵循前置文档中待完成的客户文件删除限制。

本人接口（真实 secure/account middleware，private, no-store）均在 `/api/platform/career/mentor-intents/:id` 下：GET /rating 读取当前 completed 与本人反馈或 null；POST /rating 用闭合命令记录；GET /rating/operations/:operationId 核对原操作。没有公开评分列表、运营代评、公开完成 issuer、房间读取或第三方外发。现有运营意向列表没有评分、反馈文字或会议链接。

Web 每张实际 completed 卡只读检查反馈状态后显示一次 1–5 分、可选一句话和跳过；初始不选分数。组件与请求客户端、控制器分离。写入仅由本人点击触发；未知结果保留原 nonce/命令，刷新列表不代替原操作回执；可显式核对或原操作重试。暂停/离线/账号变化隐藏私人反馈，恢复只读、不自动再提交；无浏览器存储。未确认写入离开时用原生页面提醒；关闭页面后从本人反馈记录核对结果。完成或取消卡不再提供旧会议链接。

## 会后反馈在页面中断后的恢复

原评分控制器由历史卡片拥有；网络断开、列表读取失败或重新分页使卡片卸载时，控制器也被清空，造成尚未确认的提交失去原操作恢复入口。实际 Chromium 中复现：POST 丢失响应后离线再上线，恢复按钮和离页提醒同时消失。

现由 `MentorRatingScope` 在当前账号页面内持有控制器。普通只读卡片离开时释放；只有未核对的提交继续保留原 operationId、评分/跳过与原正文。列表暂时没有该预约时，页面另显示恢复入口；重新联网只读取，用户明确点击才核对或按原操作重试。当前记录显示了已保存评分也不替代原操作回执。回执确认后释放离页提醒；不再显示新的评分表单供重复填写。隐藏、离线时移除私有内容；退出账号、换账号或离开整个页面时清空。未写入 localStorage、sessionStorage、IndexedDB 或 URL；重新打开网页仍通过服务器读取已保存结果，不承诺跨刷新保留未确认命令。

入口统一为 05 §0.3 / §2.15 的 `/me/mentors`，旧 `/community/mentors` 保留兼容。会后反馈输入框适应手机宽度，评分选项保留足够触摸区域。

验证：新增 6 项页面生命周期测试和 1 项待核对表单测试，包含在 Web 全套 780 项通过结果中；类型检查与构建通过。实际 React StrictMode / Chromium、虚构账号请求端口复现并修复离线卸载，检查列表读取失败时恢复、只发一次 POST、GET 使用同一 operationId、成功提示、离页提醒解除及账号过期清空；检查 390×844 和 1440×900 无横向滚动，手机浅色反馈及深色恢复截图已查看，控制台无错误。这是实际组件配虚构请求端口的浏览器验证，不是真实登录、生产 API 或数据库端到端验收。后端协议未改，本轮无新迁移、付费调用、部署或主预览改动。构建仍有既存的大于 500 kB 分块提示，主 JS 为 704.49 kB（gzip 200.53 kB）。
