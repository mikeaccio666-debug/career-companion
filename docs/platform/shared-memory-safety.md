# 共享记忆的真实安全分级来源

依据 02 §10、03 §8 与 15 §6。这里实现本人已复核记忆的内部来源与分级链路；本人确认、类别和敏感度仍由本人管理流程决定，不能代替安全分级。旧记忆依照产品负责人 2026-10-08 的决定，先由本人复核，不自动确认。

## 来源、授权与请求

`SharedMemorySafety` 接入 `buildApp` 的内部服务，调用者只能给出服务端捕获的真实账号会话和记忆 ID。没有新增学生 HTTP 分级接口、自动保存触发器或轮次服务。`runCurrent` 在真实 PostgreSQL 有限时事务中读取本人归属、当前学生会话、法律与邮箱门禁、认证记忆正文及不可变操作版本；不接受调用者的正文快照、来源坐标或 L0。

迁移 054 将一次分级绑定到实际记忆 ID、操作 ID、提交版本和检测器版本。来源密文只保存正文摘要与坐标，不复制正文；认证绑定 owner、来源 ID、提交版本。每次实际执行捕获真实会话版本、递增 generation、数据库时间的 5 秒租约和单次执行 token。请求准备、HTTP 发出和结果提交分别重读当前来源与会话，当前已启用检测策略也必须与配置的内容摘要和审核摘要一致。

模型使用现有 `safety_classify` 服务端路由、真实 ProviderRuntime 与 requestAdmission。HTTP 请求发出前，账本的实际预留已提交，并在来源锁和当前授权检查下转为已准入；等待供应商响应不持有事务。请求与结果受约 1 秒分级期限约束，供应商请求超时为 700 毫秒；不合作的注入 runtime 也不能迟到写入 L0。数据库连接获取和失效后的清理各有自己的有限时限制，因此这些数值不是全产品响应时间保证。

未配置审核策略、当前策略文件损坏、供应商关闭、超时或失败不会制造 L0。审核关键词命中 L2 时不发模型请求；关键词命中 L1 时模型不能降成 L0。失败时只保留实际关键词命中的 L1/L2；没有命中则明确不可用。当前策略文件损坏会关闭新的记忆分级，不阻止 API 启动或认证历史记录的读取；已有历史内容不依赖把损坏文件重新解释成有效策略。关键词与审核元数据的工程校验不能证明临床有效性或专业审核已经完成。

## 账本与读取条件

分级与问卷、起名共享同一个账号的 UTC 日调用次数额度，不能因换记忆或换来源重置。任何尚未结算、缺失或非法用量也阻止下一次模型请求。实际已发请求的用量在正文变化或会话重置后仍结算，不能因结果被拒收而丢弃费用记录。这里是调用次数和实际 token 用量账本，没有新增美元 `CostGuard` 或生产预算批准。

完整分级结果以密文绑定实际来源、claim、执行 token、检测策略和真实已准入且完成的供应商调用凭证。读取时再次核对账本，不只信任 SQL 的 level 字段。已完成来源不能改写或删除；正文内容相同、检测策略仍是当前版本时可复用该条记忆的实际 L0。改变正文、复制成另一条记忆或更换检测策略需要新的实际分级；改变敏感度仍立即按当前本人记录生效，不被旧 L0 覆盖。

`SharedMemories.selectInTransaction` 先认证当前本人记录并要求实际 full L0，再应用类别、发言者、敏感度、有效期和用途规则。本人新建或复核成功，只意味着保存完成，不代表已经进入模型上下文。返回的引用仍是待写入的候选，不是一次模型使用记录。

## 风险与删除

实际 L1/L2 结果在同一提交中写入加密、不可变且不含正文的待处理风险凭证。修改正文、归档或删除记忆不会自动把风险变成已处理。内部选择器在账号仍有待处理凭证时不返回记忆；删除之后仍保留真实风险引用和实际费用记账，账号删除则级联清理。

物理忘记记忆会删除其分级来源和其中的认证结果，但不删除上述不含正文的凭证。它们引用实际不可变本人操作，不能引用虚构消息或轮次。这里尚未实现资源卡呈现、抢占、次日回访、误报澄清、已处理凭证、覆盖状态或安全事件的最终保留期限；待处理记录因此不会自行解除。它不是开放给学生的完整危机流程。后续必须接上专业审核模板、真实呈现和跟进链路，再按产品规格处理解除与保留，不能用更新 SQL 或超时当作用户已经获得帮助。

## 验证与尚未完成的接入

测试运行在远端 Mike 账号的隔离 PostgreSQL schema；供应商 I/O 只能重定向到测试拥有的 localhost HTTP 服务。用户、正文、审核策略、供应商结果和报告 token 数都为虚构资料，不调用付费模型，也不证明真实模型分类质量。

真实数据库和协议检查覆盖来源绑定、实际请求准入与完成记账、本人权限、当前协议与检测策略、请求期间修改正文或重置账号、同正文隐私调整、检测器换版、已完成结果不可改写、账本损坏拒绝、超时、账号删除及忘记后的风险保留。另验证问卷与记忆双向共享额度、历史未知用量阻止新请求、额度不能阻止命中的 L2 关键词，以及 L1 不能被供应商 L0 降级。检查数量和完整回归结果以对应 PR 和私人验证回执为准。

主预览与其数据库未更新。没有学生聊天调用、真实 `platform_memory_uses` 写入、资源卡呈现或付费质量评测。本模块不解除 [PR3 评测前置门](agent-evaluation-preparation.md)；[调整顺序的提案](engine-gate-sequencing-proposal.md)仍待产品负责人决定。后续实际轮次必须在请求前重读记忆与风险状态，遵守当前安全门、费用护栏、执行租约、输出验证及使用记录持久化。
