## 如何恢复浏览器连接

远端服务已经运行时，在 Mac 的本项目终端运行：

```sh
./scripts/preview-remote.sh
```

保留该终端打开，然后访问 http://localhost:4321。停止转发用该终端的 Ctrl+C；这只停止预览连接，不停止远端服务。当前转发已由 Codex 启动，端口占用时不要再启动第二份。网络断开、Mac 休眠或 SSH 结束后，可在原转发退出后重新运行。脚本不会自动停止占用端口的其他进程。

SSH alias 必须已配置并有可信 host key；脚本不会降低校验或自动授权连接。3120 / 3121 仍只监听远端 loopback，没有把开发服务发布到公网。

## 编辑和重启的边界

Mac 与远端是两份代码。当前已同步的源码可以运行，但 Mac 编辑不会自动同步或触发远端 API 重启。继续开发时应明确本次编辑在哪份 checkout 中，并精确同步必要改动、重新检查与重启对应服务；不要覆盖私有环境、数据库、附件或模型目录。远端浏览器／CLI 执行能力也须各自验收，不能由普通聊天成功推断。

远端 API、worker、web 与语音进程当前为本人账号的独立开发进程，PID/日志留在私有 state。它们可跨普通 SSH 断线继续运行，尚未配置系统启动服务或生产自动恢复。服务器重启后，需要重新启动专用 Docker 服务和本人进程；继续开发的 Codex 可按私有记录完成恢复。停进程前须核对 PID、实际命令和工作目录，不能全局 pkill 或停止其他项目。
