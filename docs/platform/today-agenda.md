# 今天的日程与简历待确认摘要

依据产品 05 §2.2 今天页区块、08 的任务卡与等宽数字。`GET /today/agenda` 已接到真实数据库；网页 Today 在本人安排之后显示日程和待确认简历。

## 内容

- 日程来自本人保存的面试与岗位截止。使用保存的每日时区和数据库时钟决定“今天”；面试区间与今天有交集时列出，恰在今天零点结束的不列出。取消或已结束的面试不列出。
- 展示面试/截止类型、原记录的公司与职位、用户时区的时间；原记录时区不同时再显示原时区，均带 UTC 偏移，避免夏令时重复时刻混淆。面试另有结束时间。
- 面试链接打开实际安排；截止链接打开岗位收藏。截止只代表用户录入内容，不保证岗位仍开放；过去的当日日程仍可回看。
- 待确认摘要目前明确为 `scope=resume_reviews`，界面标题为“待你确认的简历”。只计算 pending 且未到期的真实原稿审核记录，显示数量和最早到期时间；已确认、拒绝、被新版本替换、过期记录都不计入。读取不会伪写过期操作。
- 无日程时不显示日程区块；零份简历用真实空状态。读取失败显示不可用，不冒充零份。
- 休息有效时接口不返回待确认摘要，页面也隐藏提示。原本保存的日历仍可查看；“都关掉”关闭提醒偏好，不删除用户日程。本轮没有发送提醒或创建通知任务。

## 数据与界面边界

共享契约校验账号、时间、日期交集、重复条目、休息与 pending 的一致性；嵌套对象和数组保持冻结。后端各来源都在同一有界事务及账号锁内，通过现有解密、最新不可改写操作回执核验。岗位与面试各完整读取最多 500 条；超过即不可用，不能用 UI 第一页冒充完整集合。

显示用公司/职位投影单独提供给本接口，`TodaySources` 的规划元数据仍不带这些自由文本。日程不返回 JD、原稿、笔记、原问答、外部 URL 或凭据。响应 private/no-store，沿用固定账号、会话、来源与限流校验，结束前再查会话撤销。

前端复用有超时和账号代次检查的读取控制器，离线、隐藏页面、切换账号会清空并取消读取；失败不会保留旧数字。休息保存后重建日程读取；晚到响应不能复活旧待确认。即使安排接口先读到休息、摘要还没刷新，也立即隐藏待确认区块。没有任务自动完成、对外发送、模型请求或执行授权。

## 验证

- 新日程服务实际 PostgreSQL 6/6；现有 Today 来源 11/11、实际 HTTP 1/1，共 18 个场景通过。覆盖 25 小时的夏令时日期、跨夜与零点边界、取消/完成、55 条完整集合、他人隔离、真实简历版本与过期、休息、密文损坏、准入撤回、晚撤销及取消。
- 契约 76/76、Web 848/848；API 类型检查和 Web 生产构建通过。
- 实际 `TodayAgendaContent` 的虚构资料 SSR 显示检查：390×844 与 1440×900 无横向溢出，桌面内容宽 680px，链接触控高度 44px；双时区、休息及空状态已检查。此为组件显示验证，HTTP/控制器分别验证真实读写边界，未宣称完整登录后的浏览器端到端验证。
- 运行记录和临时预览位于忽略的 `.local/verification/`，主预览不重启。

## 剩余功能

这不代表 Today 或 P0-6 完成。自定义提醒、其他类型的待确认汇总、队伍动态、本周统计、第一封信/晨报、自动三件事和调度仍待完成。旅程重心依赖第一封信真实送达；当前 C1 固定介绍不能代替该证据，本轮未虚构初见完成或旅程阶段。

本轮无数据库结构变更、主库迁移、付费模型调用、合并或部署。
