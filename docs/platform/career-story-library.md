# 项目事实与本人确认的故事库

依据 03 §2.3、§3.4、§6.8、§8.5，05 §2.16，07 P0-9，09 §3A。实现本人录入的项目事实、英文 STAR 正文、中文要点、题型标签、真实版本关联与确认。不是完整旅程、前辈提议、面试练习存档、模型材料生成或已验证技能。

## 用户路径

入口 /journey/stories，故事独立入口 /journey/stories/:id。诞生后的入口及设置页有故事库链接。用户先录入项目事实，或直接新建故事草稿。课程项目、独立项目、实习、工作、志愿与其他经历均由本人选择类型；不默认成工作经历。敏感度必须本人选择，不预选普通。项目事实分别记录团队背景、本人行动和结果/反馈，发生时间由本人明确填写；想不起事实时可先保存未确认的故事草稿。

故事英文正文与中文要点分别按 situation/task/action/result 保存；桌面两栏，手机编辑时切换语言。标签覆盖主动承担、不确定、分歧、协作、问题解决、领导和学习。没有模型填空、自动翻译、编造数字、自动升级教授点评、默认实习或能力认证。

点击本人确认后，项目从 self_reported 变为 user_confirmed；故事从 draft 变为 confirmed。服务端记录真实确认时间、实际版本和不可变操作。正文或标签、关联、敏感度、标题等任一编辑产生新版本并清除确认；需再次明确确认。故事确认要求英文四段完整；不要求生成不存在的结果数字。不完整内容可一直保持草稿。项目确认要求本人贡献非空。确认不是导师审核、面试评分或独立验证。

## 真实关联与隐私

故事只能关联本人数据库里真实存在的 active 项目及用户选中的实际版本；跨用户/未知来源拒绝。关联类型必须保留真实项目类型，故事敏感度不得低于关联项目。草稿可以引用尚未本人确认的事实，确认故事前所有关联事实都须处于当前确认版本。

项目变更、撤回或移除后，故事本人历史确认状态不被系统擅自改写，但 evidenceAvailability 分别成为 stale、withdrawn 或 missing；未确认关联为 unconfirmed。只有 current 才表示关联仍可用，不表示已安全分级、已被模型使用或具备执行授权。需要用户修改关联并再确认。删除项目不默默删掉本人另外保存的故事正文；关联失效在界面中明确显示。

普通、敏感和受限的数据均只经本人账号页面读取。保存成功与本人确认不产生 L0、队员共享、工具租约或模型使用凭证。主理人/队员的正文读取、当前来源分级、敏感度过滤、真实引用与模型使用持久化仍待后续接通。现阶段没有学生 Agent 路径读取这些正文。已接通的内部元数据准备索引与当前版本复核见 [真实资料来源](career-preparation-sources.md)；索引不包含这些正文，也不授予读取或模型使用权限。

## 存储与授权

迁移 057 新建 platform_career_evidence（当前只接受本人项目事实）、platform_career_stories、platform_career_library_operations。withdrawn_at 核对真实不可变撤回操作的时间，后续编辑不改写该时间；mentor_review 当前仅为空，不制造导师凭证。完整记录包括标题、发生时间、正文、标签、关联、类型及确认状态加密；只有归属、版本、查询状态、敏感度与数据库时间作查询投影。密文认证表、owner、ID 与版本，读取核对所有投影、最新不可变操作，以及实际确认操作的时间与版本。不能恢复旧有效密文来回滚确认、编辑或移除。

所有接口核真实学生会话、账号窗口、CSRF、额度及固定会话。账号锁串行化操作；expectedRevision 防止覆盖更新。稳定 operationId 重试返回真实当前记录，改变请求或改成另一种记录复用操作 ID 被拒。物理删除擦除记录密文，保留不含正文的加密请求摘要与坐标；迟到创建重试不能复活。账号删除级联清理记录与操作。新建、编辑与确认要求当前法律/邮箱准入；私人读取、撤回事实和删除在准入撤回后仍可进行。中途真实会话重置使记录与操作一起回滚。

项目、故事各最多 500 条，每页 50 个摘要，不带事实或 STAR 正文。关联选择逐页读取全部本人项目，不只展示最新一页。正文按需读取，不默认展开受限内容。账号切换或离开页面取消请求并清空私人组件内存；不写浏览器持久缓存。未知写入结果保留原操作 ID，供原请求重试。

## 成长记录的范围

项目来源从真实当前解密项目账本调用原 careerProgress，subjectId 为同一个实际项目 ID，referenceId 指向真实项目记录版本。self_reported 仅计临时项目记录；本人确认才按既定规则计项目记录；修改失去确认，撤回/删除不计。没有导师审核凭证或导师身份字段，不允许本人把 verification 改成 mentor_reviewed/observed。现有 HTTP 接口已合并本人投递声明，coverage 为 project、application，见 [本人成长记录](career-progress.md)；其他类型尚未接入，零值不代表现实中从未做过，也不代表完整成就系统验收。故事数量不等于技能、项目能力或面试成绩。

## 接口与验证

本人 /career/projects 与 /career/stories：GET 分页、GET /:id、POST 创建、PATCH 完整编辑、POST /:id/confirm、DELETE /:id。项目额外 POST /:id/withdraw；故事没有自动撤回或专家 proposed 写入器。GET /career/progress 返回真实账本派生结果和覆盖范围。所有响应 private, no-store，客户端不能设置 owner、来源、确认、审核、状态、练习次数或确认时间。

真实 PostgreSQL 与真实密码登录 HTTP 覆盖跨用户、源版本/类型/隐私关联、并发编辑、确认与编辑失效、正文加密、原操作重试、删除防复活、旧有效密文回滚、真实确认凭证、准入撤回、真实中途会话重置、分页、账号级联删除与重复执行迁移。协议用虚构传输值校验归属、字段、状态和版本，不替代真实数据库证据。成长结果与纯规则在同一真实账本上逐字段对比。

检查结果以对应确切提交及私人验证回执为准；构建和请求测试不等于浏览器视觉验收。本次不调用付费模型、不提交真实申请、不部署，也不更新主预览或主数据库。前辈提议、面试素材接入、实际练习统计、材料引用、故事阶段退出判断与其他类型成长记录仍待实现；不解除学生对话引擎的评测前置门。

## 保存中断后的核对

故事和项目页面的列表、详情、关联项目读取及写入最多等待 8 秒；传输忽略 abort 时也会结束等待，迟到结果不能覆盖后续状态。超时只表示结果未知，原操作 ID 和草稿留在当前页面内存，不自动创建另一条保存请求。

新增本人只读 GET /career/stories/operations/:id 与 /career/projects/operations/:id。接口在同一有界事务里核对真实固定会话、账号锁、原操作认证密文及当前版本；记录不存在时，还必须找到真实删除凭证，不能把缺行当成已删除。返回原操作的实际 revision 与当前记录，允许显示后来修改的版本或已移除状态。跨账号、错误记录类型、未知操作不能读取；邮箱准入撤回后，本人仍可核对以前的保存。响应 private, no-store，不重发写入或记录新的 story_saved。

界面提供「核对这次保存」和「用原操作重试」。前者仅 GET，404 也不会抹去未核对操作；后者仍使用原命令及操作 ID。断网清除已展示的列表和详情，保留草稿与未核对命令，恢复网络只读列表。列表读取失败时不把一条恢复结果充当完整列表；核对成功后重新取列表。新保存前必须有可用的当前列表，正文确认仍绑定原有版本规则。

账号失效与卸载取消请求并清空私人状态；浏览器持久缓存不保存正文、草稿或命令。未核对操作存在时注册离页提示；该提示不能保证拦住浏览器强退或用户选择离开，页面销毁后须重新查看实际保存记录，不承诺跨刷新恢复草稿。

本批检查：8 项网页请求/超时测试、13 项真实 PostgreSQL 与密码登录 HTTP 测试通过，共 21 项（新增 6 项）；Web/API 类型检查及 Web 生产构建通过。实际 React 页面在 StrictMode 下用虚构客户端检查 390×844 浅色/深色、1440×900 浅色，截图已检查，无横向溢出。故障流程覆盖 8 秒无响应、只读核对 404、断网、重新读取失败、恢复核对、迟到写回包和账号失效清空；手机流程只有最初 1 次写入、2 次只读核对，无 localStorage/sessionStorage 内容。浏览器 fixture 与真实数据库验证分开，不代表真实登录浏览器端到端或主对话验收。无新迁移、主预览更新、付费调用或部署。
