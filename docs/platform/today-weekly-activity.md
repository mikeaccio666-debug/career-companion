# 今天页：本周你做了什么

按产品 05 §2.2 的三格记录，将实际故事修改和简历确认接入 GET /today/weekly 与今天页。练习题目当前返回 null，页面显示「暂未开放」；不把尚未接入的练习来源写成零，也不把已完成的面试日程当成练习。

## 统计含义

按本人保存的时区，以当地周一至当前数据库时间为本周。跨周和夏令时不按固定 168 小时截断。客户端不能选择 owner、时间、时区或提交次数。

- 改过的故事：真实 story edit 操作回执，按仍保留的故事 ID 去重。只创建或确认故事不算修改；同一故事编辑多次只算一个。本人私有故事也计入本人统计，正文及敏感度不进入响应。
- 确认过的简历：真实 approve 操作、确认决定和对应版本正文摘要共同验证，按仍保留的原稿对象 ID 去重。归档、被新稿替换不抹掉真实确认行为；同一份重复确认不刷次数。这里只覆盖本人原稿确认，尚未覆盖全部四类待确认材料。
- 删除对象后不再计入。统计只描述仍保留的本周行为，不是终身累计、技能掌握、质量评分或成功率。

查询从真实来源服务发起，验证不可改写回执的身份、动作、时间和版本，再验证当前记录及其最大修订。简历历史确认还核对请求摘要、原决定和对应真实内容摘要；旧确认不能冒充新版本确认。

## 读取与页面

每日偏好服务核实真实主理人、会话、邮箱与当前协议，在同一个账号锁和事务内读两个来源。每类本周操作最多 1000 条、对象最多 500 个；超限明确失败，不返回第一页计数。读完再次核会话及取消信号。响应只含 owner/companion 坐标、日期、时区、两个计数与明确的覆盖范围，不含故事/简历正文、对象 ID、操作 ID、令牌或密文。

网页使用共享契约和固定账号客户端，复核归属；通过现有 JourneySectionController 读取，10 秒超时。失败、断网、页面隐藏、账号变化及卸载清除旧计数；恢复可见或联网后重新读取，不写入浏览器存储、不轮询、不乐观加一。接口 private, no-store，仅 GET。此本人查看功能不触发模型、提醒、任务、晨报或自动完成。

桌面三列、手机纵排，沿用设计系统的浅深主题。真实零记录与读取失败分开显示，提供故事库和简历入口。页面只展示这次读取对应的日期范围；跨周需重新读取。
