# 求职知识准备与统一读取

依据产品 04 第 4.6 节、09 第 3C 步和 15 第 4.2 节。CareerKnowledge 将本人资料与明确选择的已授权题库合并为统一读端口，并为准备流程提供一条真实知识访问引用。它是内部数据组件，尚未注册到学生对话执行器；完整专家运行记录、任务租约和真实聊天 citation 持久化仍需接入。

## 账号与读取范围

服务端以捕获的 FixedSessionContext 打开绑定，明确指定已开放的发言者、组织和可选题库结构化筛选。绑定复制会话与筛选，不接受 ownerId、entitlement 或运行状态作为授权参数。每次读取再核对实际会话、学生账号、邮箱和现行条款；调用者 ownerId 必须与绑定一致。外来账号、会话重置、取消或权限完整性无法证明时，不返回段落。

私人资料沿用 KnowledgeSources 的词法检索，组织内容沿用 P0 的结构化筛选；两者共享同一条实际连接和默认 2 秒的 bounded transaction，避免嵌套事务占住同一账号锁。组织、权益、许可用途、受众、有效期和来源状态仍在 LIMIT 前过滤，段落仍经过正文哈希与实际内容核验。方法卡和模式卡不进入这个通用检索接口，继续按技能及场景加载。

每段返回原始文字、数字 revision、passageId、版本登记时间、scope、可选 assetClass、服务端出处标签与 untrusted_knowledge。私人资料一律标「你的资料」，用户自行填写的 sourceLabel 不能冒充蔓藤出处。没有命中就返回空集合。

私人排序分数与组织结构化顺序含义不同，因此合并保留各自顺序并交替取段，不制造一个统一匹配分数。合并后最多 8 段、48 KiB，保留完整段落，不截断到引用无法核对的部分。AbortSignal 在入口捕获；调用者随后更换 scope.signal 不能解除原取消。

## 知识访问引用

绑定保存当前全局发布序列值，尚无发布时为 1；同时保存 orgId、orgScope、entitlementId、entitlementRevision 与实际 audienceGrants。组织读取限制为该组织、且 publish_batch 不超过捕获的值，新发布的题目不会混入旧绑定。

readKnowledgeAccess 返回一条 knowledge-access:<userId>，revision 为捕获的发布批次，ownerId 为真实账号。empty 根据当前本人来源及实际可读题库判断，只说明此次准备的知识情况，不授予执行权限或保证模型可以完成技能。准备组件在已有事务中消费这条引用；没有实际档案或执行器的输入仍保持缺失，prepareCareerRun 继续 blocked。

授权撤销或到期后，旧绑定变为 withdrawn，组织读取拒绝；授权版本或范围改变时变为 stale。已经观察到的 withdrawn 或 stale 对该绑定保持有效，重新授予权益不能让旧绑定复活。新的绑定在没有当前权益时保留 current 知识引用、orgScope 为 none，只查私人库；后来获得权益也不扩大这个私人绑定，须重新准备。空资料库仍可有真实的 current 访问引用，空结果不伪造知识内容。

## 验证

隔离 PostgreSQL schema、真实私有授权文件和实际密码登录验证合并读取、数字引用、标签、账号隔离、八段与字节预算。测试还验证新发布批次排除、另一组织排除、真实权益撤销、重新授权、到期、状态密文篡改、会话重置、取消和已取消访问日志的事务回滚。

准备集成测试证明真实知识输入恰好一条，且缺少真实档案或执行器时仍 blocked。ready_for_draft 与撤权后 blocked 的纯领域测试，其余输入和工具状态明确是虚构夹具；这些状态不代表产品已开放真实执行器。

共 63 个相关 API 检查、194 个 career-core 检查通过；全仓类型检查及最终 API 类型检查通过。中文测试集仍为 30/30，仅适用于已定义的虚构集；真实内容质量需独立验证。测试没有商业模型网络请求、真实申请或生产组织权益导入。

## 运行持久化与对话接入

当前绑定只存在于服务内存，重新启动会丢失它；它不能从客户端 JSON 恢复，也不能替代真实租约或完成回执。产品要求的 platform_expert_runs 知识批次、组织范围和输入版本持久化尚未实现，必须随真实运行记录接入。现有 preparation_lookup 日志仍不声称某条模型消息已经使用来源。

完整学生 engine 的评测顺序待决事项保持原边界。后续须将绑定与真实轮次、任务租约、技能权限和来源准入关联，持久化本轮实际返回的 citation，服务端校验输出引用，再把标签接到聊天回复。读取端口通过不代表这些上线条件已通过。

本切片不新增学生 HTTP 或模型工具注册，不新增运行表，不部署，也不修改主开发库和当前预览。
