# 第一封信的学生进度读取

2026-10-09。初见 C7 原来固定显示“第一封信还没有生成”，无法反映后台已经保存的原稿与复核。本次用实际进度接口替换固定提示。

## 数据链与界面

GET /api/platform/companion/first-letter/progress 只读取当前已登录学生的 direct_letter 初见路径。固定账号上下文、当前邮箱/协议/安全来源、真实 welcome 选择及出生依据均沿现有服务核验；拒绝查询参数，响应 private, no-store。

FirstLetterProgressService 在同一用户锁和有界事务中解码任务、阶段密文与实际费用证据。复核状态复用 FirstLetterGeneration.readReviewInTransaction 的完整历史判断，不从一条 status 字符串推断通过；readReview 也复用这个事务内入口。

| 状态 | 依据 | 页面说明 |
|---|---|---|
| not_started | 真实 C7 选择存在、尚无准备任务 | 写信前的准备还没有开始 |
| prepared | 已认证准备任务存在、尚无执行阶段 | 准备已保存，等待开始写信 |
| writing | 原稿阶段 running 且执行租约仍有效 | 正在写第一封信 |
| draft_saved | 原稿或后续结果已保存、下一阶段尚未开始 | 信稿已保存，等待继续核对 |
| checking | 合法下一复核/重写阶段 running 且租约仍有效 | 正在核对和调整信稿 |
| interrupted | 失败、不确定、过期执行、来源变化或最终复核未通过 | 写信暂时停住了，已有进度已保留 |
| reviewed | 完整持久化阶段被重建为 reviewed_draft | 信稿已完成核对，等待送达 |

返回仅含 ownerId、companionId、welcomeId、state、capturedAt 和 delivered=false，不含正文、事实、任务/调用身份、费用、供应商或执行凭据。prepared/reviewed 描述已保存的历史进度，不授予在当前日期或配置下继续执行/发布的权限。

损坏证据或无法重建的复核返回读取失败，不伪造成 not_started 或 reviewed。该接口不调用模型、不协调费用、不更新准备、不创建任务、不发布信件，也不完成 C7。

网页只在真实 C7 时加载面板，使用账户绑定客户端并比对主理人和 welcome 身份。初次加载及“查看最新进度”都为只读请求；10 秒超时。失败清除旧进度；暂停、离线、页面隐藏、卸载或账号变化时停止读取并清除观察值，恢复可见和在线后重读。没有后台轮询或本地持久化；后续 worker/发布订阅需另行接入。
