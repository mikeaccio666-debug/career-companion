# 每日规划的主理人行为来源

依据产品 02 §2.3 的 Q4A 规则和 05 §2.2 的每日计划规则。`CompanionPlanningSources` 已在 `buildApp` 中接入 `TodaySources`，从真实已诞生主理人的已保存问答读出 `fifteenMinuteSteps`。

## 规则与范围

- 实际回答 Q4A 时为 true，后续选取器据此排除超过 15 分钟的候选，不把一个更大的任务伪改成 15 分钟。
- Q4B/C/D 为 false。真实跳过或快速通道也是 false，但 provenance 保留 `questionState=skipped` 和 `fastTrack`，不是伪造用户选择。
- `scope=birth_answers` 明确当前只覆盖初次问答。主理人后续版本必须接入自己的真实变更历史；不支持的版本拒绝读取，不能用旧答案替代。
- 输出仅有归属、主理人、版本、规则布尔值和来源坐标，不含完整问答、基本资料、名字、性格卡、示例句、情绪原文或认证令牌。

## 实际来源核验

读取先固定会话、锁定本人账号并检查学生身份、当前协议与邮箱。真实诞生库核验主理人和原始诞生回执，已完成生成读取器核验问答命令历史、加密种子与完成结果。随后在同一事务中再次读取已锁定的问答，核对问答、任务、草稿、修订和 source receipt version 与诞生捕获一致。

只有解密成功不够：将 Q4A 改成 B 后重新加密，也不能绕过原始命令证据核验。读取结束再检查会话，晚撤销或取消不能发布来源。主应用模型开关关闭时仍可读取有效的历史来源，不重新生成；缺少历史证明的旧任务保留原来的真实来源门槛，不伪造历史证明。

`TodaySources` 把本来源纳入内容摘要，并再次核对主理人与每日设置属于同一账号、同一个实体。它没有新增公开 API，不接受浏览器提交的行为参数。

## 尚未完成

本来源不代表当前危机/低落覆盖、旅程重心或练习回执已经接通，也不授予模型调用、计划生成、外部执行或发送通知的权限。初见/第一封信、当前安全准入与完整自动计划仍由后续消费流程逐项核验。自动三件事和晨报没有因此开启。

无数据库结构变更、主库迁移、部署、模型付费调用或学生 UI 改动。
