# 学生页外观偏好

依据产品 08 §2.1、§2.5 和 §7.13。「我」页新增跟随系统、浅色、深色三种外观；默认跟随系统。设置只保存到本浏览器，页面明确说明，不作为跨设备同步的账号偏好。

## 行为

- 只保存一个封闭枚举，不保存用户 ID、邮箱、资料、对话或认证信息；不发网络请求。换账号不改变设备外观。
- 应用入口在 React 首次渲染前读取偏好；显式选择写入根元素 data-theme，跟随系统移除该属性，由既有 CSS 媒体查询响应系统变化。
- 同源其他标签页的有效存储变化、清除站点数据及 pageshow 恢复会重新读取当前值，避免旧 storage 事件覆盖较新的值；不把读同步变成写同步。未知值按跟随系统处理。
- localStorage 不可访问或写入失败不阻止显示与切换，提示「浏览器暂时无法保存，选择只在当前页面生效」。之后再次选择可重试保存，不谎报已保存。
- 原生 radio group 支持键盘方向键，选项文字、选中状态和焦点均可访问。离线时当前有效账号仍可调整本地外观，账号私有内容继续由原页面控制。
- 两个带 media 的 theme-color 元素提供浅/深默认；显式选择时两者同色，跟随系统时恢复各自默认。PWA manifest 的静态背景与默认主题色改为产品浅色纸色；安装后的系统启动屏是否立即采用新 manifest 由浏览器决定。
- 共享记忆页与独立面板接入统一 career-design-tokens，移除不理会显式浅色选择的局部系统深色覆盖。

本批只接通现有学生组件的外观选择；旧工作台、登录/协议页面的完整视觉迁移、五栏外壳与主对话 UI 仍按 09 继续。没有扩展工作台、改变产品方向或放行模型评测门。
