# 共享记忆分类与待处理记录的私有导出

对应产品 09 §11、13 §4.5：用户导出自己的数据时，共享记忆分类来源和仍保留的安全处理记录也需要覆盖。这些记录属于账号本人，不是可注入主理人上下文的共享记忆。

`AccountCoreExport` 在原有密码再验证和同一次 REPEATABLE READ 事务内调用 `AccountMemorySafetyExport`，增加：

- `memorySafetySources`：来源 ID、记忆与原操作引用、提交版本、内容摘要、采集时间及当时的策略版本/摘要；真实 pending/running/detected 状态、代次、错误类别、租约截止时间；已完成时的分类与策略。没有完成的结果保持 null，过期 running 不会因导出而重试或变成失败。
- `memorySafetyBlocks`：原处理记录、来源引用、发现时间、当时分类与策略，以及已核对的模型用量（关键词降级没有模型用量）。原记忆已经经过删除保留期并清除时，仍能导出实际保留的处理记录；不恢复正文，也不自动标记已处理。

读取复用已有密文上下文与回执校验，核对来源、原操作版本、处理结果和真实已完成用量。来源存在时，处理记录必须与它一致；检测到 L1/L2 却缺少处理记录，整份捕获失败。分类策略后来更新或原记忆正文被修改，不会重写历史结果，也不意味着旧结果允许当前正文进入上下文。

两个表使用所属用户和 ID 游标，每页 100 条完整读取。新增读取不获取工作锁、不创建来源、不运行模型、不改业务数据；总大小仍服从账户导出的 16 MiB 上限，超出必须转归档 worker，不能截断成功。密码再验证凭据只随成功事务消耗；取消、坏密文、所属用户不符、失效会话或读取失败不返回部分资料。

输出采用字段白名单，排除密码、会话摘要、认证版本、租约令牌、执行令牌以及原始密文。撤回模型同意或邮箱尚未重新验证，不妨碍已登录本人完成密码再验证后取得历史资料。

本次无数据库迁移。实际覆盖增加两表：核心捕获 100/164 个待投影表，剩余 64；带私有文件捕获 103/164，剩余 61。总清单为 171 表、7 个有依据的豁免。`complete=false` 保持不变；这不是已完成的自助下载端点，也不代表其余安全记录、组织数据或完整账户导出已经交付。

验证使用虚构账号、独立 PostgreSQL schema 和 loopback 模型协议，包含完整分类、关键词降级、原文修改、策略更新、过期运行、删除后的历史记录、105 条分页、密文损坏/串户、缺失处理记录、用量不一致、晚到失效、取消与容量回滚。未使用真实用户资料或付费模型。
