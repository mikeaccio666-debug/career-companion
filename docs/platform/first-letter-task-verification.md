## 实际覆盖

1. 用真实 O2 指令、诞生和 direct_letter 选择建立准备记录；两个并发 prepare 和重复请求得到同一身份。新建 FirstLetterTasks 实例可从数据库重读并重构相同准备；没有新增供应商调用、消息、任务队列记录或费用预留，也不推进欢迎状态。
2. 日期、队员名单或版本变化返回 409 且不覆写；外部账户任务 ID 返回 404，伪造会话和额外输入字段拒绝。
3. 损坏、移位密文及修改行上的来源摘要均阻断读取和账户导出；失败不消耗账户重新认证凭证。
4. 撤回协议、邮箱未验证或当前安全凭证损坏后不能继续 live read/prepare；账户本人仍能导出已退役主理人的历史准备记录。
5. 插入后才撤销会话或取消操作，事务回滚、不留下任务。
6. 用户、welcome、conversation、birth receipt 的跨账户关联被真实数据库外键拒绝；删除用户级联清理其任务，不影响另一账户。
7. JSON 和含文件归档都包含同一份 firstLetterTasks 快照；不输出令牌、密文或复制的 prompt。临时私有归档可清理。
8. 实际 buildApp 装配内部任务服务；没有新增可供客户端注入来源或配置的第一封信任务路由。

这不是执行恢复或模型质量验证。没有启动/杀掉 worker 验证崩溃恢复；没有持久化模型调用、费用结算、重写次数或候选稿；没有写入第一封信或完成 C7。
