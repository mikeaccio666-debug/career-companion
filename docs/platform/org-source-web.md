# 学生端组织内容出处页

依据 04 §2.1、§4.4 与 08 §7.5。出处由当前服务端来源数据提供，不从模型正文、URL 或品牌词推断。本切片接通网页登录后的 /sources/org/:sourceId/:revision/:passageId；没有新建资料搜索产品，也没有注册 Agent 检索工具。没有在对话里插入假引用或示例资料。

## 数据与行为

packages/platform-contracts 的 org-knowledge.ts 定义闭合的坐标和学生出处 DTO。只允许题库与方法卡；对话模式、私人资料、较旧标记、伪造品牌标签、未知字段、访问器及非规范坐标不能进入这个界面。校验是传输数据的形状检查，不能单独证明出处真实；实际真实性仍来自账号绑定的请求、后端权限／发布／完整性核验。

org-source-api.ts 经捕获的当前账号客户端发送 GET，使用 no-store，在响应前后核对中断和账号代际，并逐项核对返回坐标。网页路由只识别规范出处坐标；无效地址显示恢复说明，不构造请求。路由不是授权，服务端仍要求真实会话、窗口账号、邮箱、现行条款、学生账号及组织权益。

方法标签由后端显示内容本身的 revision，例如「蔓藤方法 · v7」，不是发布后引用坐标的 revision。品牌前缀来自可信服务端 PLATFORM_ORG_CONTENT_BRAND，默认蔓藤，拒绝空值、控制字符、格式混淆与 HTML；网页不发送品牌或版本选择参数。

新导入来源正文采用确定性可读文本，保留题面、讲解、要点、追问、rubric，或方法步骤、停止条件与反例；内部作者／审核员账号 ID、工具声明和技能绑定不进入这些新段落。结构化记录继续独立保存并参与哈希验证。为兼容先前保存的引用，后端也接受原规范 JSON 正文；保留它的原文、原内容哈希和原引用，不偷偷改成新段落。早期 JSON 来源仍可能显示结构化文本，正式内容整理时应按当前格式重新审核导入；这不是已完成的全部历史格式转换。

org-source-controller.ts 只在页面内保存当前读取状态。开始重读即清空旧段落；超时 12 秒会结算失败，即使传输忽略 abort 也不会无限挂起。账户失效、停止、页面隐藏或离线会丢弃内容；页面重新显露或联网时重新读取。没有客户端正文缓存、localStorage、自动导出或外部来源抓取。

页面显示服务端标题、出处标签、收录月份和本次引用的原始段落。正文通过 React 文本节点显示，不解释 HTML，不执行链接或提示词。清楚说明这是参考资料，不代表用户经历或求职结果。权限失效、版本变化／撤回、来源不存在、访问条件变化和暂时不可用分别显示固定状态，不显示后台错误正文。重试仍使用原坐标，不能偷偷切到另一版来源。

沿用 career-design-tokens 与 career-surface，来源标签视觉高度 20px，链接点击区域至少 44px；方法版本数字等宽。小屏自然换行、长正文断行、键盘可见焦点、读取状态 aria-live/status。页框始终有「AI 主理人和队伍」身份。OrgSourceLabel 可供后续真实 citation 消费者复用；当前正式学生消息 DTO 尚没有 citation 列表，因此还没有把标签挂到模型回复上。

## 验证及未完成项

虚构资料、隔离 PostgreSQL schema、真实私有文件、实际密码登录 HTTP 验证 Web 客户端和控制器：读取已发布来源、撤权后清空、原坐标撤回状态、真正的会话重置、外来账号拒绝、不合法坐标与旧格式不可变证明。没有模型请求或生产许可、权益、内容导入。

React 组件通过真实 SSR 校验正文转义、服务器方法版本、月份、错误状态无旧内容、同站链接和 AI 标识；纯测试覆盖闭合数据、超时、忽略 abort、过时代际、账户失效与页面挂起。浏览器视觉／读屏／交互走查尚未完成；此前私有预览自动审批拒绝仍未绕过。SSR 和 CSS 检查不能证明 390px／1440px、深色、高对比、200% 缩放或实际读屏验收。

后续仍需完成 CareerKnowledgePort 的真实知识批次冻结、entitlement 撤销与任务租约准入、专家技能加载、真实对话 citation 持久化和服务端输出校验，再把 OrgSourceLabel 接到回复和依据行。评测许可待决事项、真实内容审核、整个学生 engine、面试练习、定期访问日志清理及 P0 上线门槛继续开放。此切片未部署、未改变主库或当前预览。
