# 模型调用记录的私有账户导出

对应产品 09 §11 和 13 §4.5 的本人数据导出要求。`AccountCoreExport` 的密码再验证与同一 REPEATABLE READ 捕获事务新增两个只读区段：

- `safetyModelUsage`：入门问答、主理人命名、共享记忆三类安全检查的实际调用 ID、来源引用、代次、检测策略版本、供应商/模型、调用状态、用量状态、输入/输出及缓存 token 数和时间。每种来源核对原始组合归属；共享记忆使用保留的原操作绑定，因此正文及分类来源经过删除保留期清除后，仍能导出实际留下的用量记录。
- `modelRelayRequests`：底座中已经存在的模型转发历史，包括原任务与请求引用、代次、供应商/模型、reserved/succeeded/failed/uncertain 状态、预留 token、实际已报告用量、错误类别和时间。读取不运行任务、不恢复或重试未决请求，也不向学生扩展通用工作台能力。

缺失、无效、未结束的用量保持其状态和 null；未记录缓存用量保持 null，只有实际记录为 0 才输出 0。预留 token 不等于实际消耗或已收费金额。安全模型用量为历史记录，不是对原输入的分类结论，也不能重新授予共享记忆注入权限。

查询只读取明确列，不读取身份认证版本、命名/记忆执行令牌或提示词正文。输出也不包含账户密码、会话摘要、租约令牌、原始异常或请求/响应正文。`requestId` 是原转发请求的去重引用，不是执行凭据。对转发任务额外检查 `job.user_id`、原 CLI 任务种类及调用代次不超过当前任务代次：旧表的单列任务外键只保证任务存在，不能单独证明任务属于同一个账号。

分页按 owner + UUID 游标，每页 100；不存在默认截断。各状态的时间与计数关系必须符合存储协议。坏引用、跨账户关系、非法计数、取消、会话失效或总导出大小超限均使整个捕获回滚，不消耗密码再验证凭据，不返回半份文件。已有撤回同意或未验证邮箱不禁止本人取回历史资料。

没有新增表或迁移。当前 171 表清单中，164 张需投影、7 张有既有豁免：JSON 已覆盖 102、剩余 62；带私有文件已覆盖 105、剩余 59。两个模式仍为 `complete=false`；其余安全/组织资料、归档 worker、自助下载与完整删除链路仍待完成。

验证使用隔离 PostgreSQL、虚构账号和受控协议。包括全部安全调用状态、三种实际来源、主理人命名与记忆真实服务路径、真实删除后的用量、转发进行中/成功/失败/不确定、105 次实际计账跨页、105 条保留转发记录、撤回同意、旧外键允许的跨账户引用，以及晚到失效/取消/容量限制回滚。转发请求使用注入的虚构响应，命名/记忆使用 loopback；没有付费请求或真实用户资料。
