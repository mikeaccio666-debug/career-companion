# 本人身份记录的网页管理

对应产品 05 §0.3、C5、08 §7.11 与 09 §3A。基于真实本人记录服务，接通 /me/profile 中的身份记录管理。当前不宣称 C5 初见对话、StatusClock 侧栏、今天页或 P0 全部完成。

## 实际入口与来源

个人资料链接使用产品已定名的 /me/profile，身份模块锚点为 identity-clock，不新增产品路由。通用链接只写“个人资料”，不对跳过身份问题的用户发补填提示。

GET /career/identity/entry 在当前固定登录会话与 student 账号下，读取实际加密 intake 快照和独立原操作。只有 intake_ready 且原 O2 答案确实为 f1_student / opt / stem_opt 时返回记录管理页可见状态及原 draft 坐标。自由文字答案还必须对应真实已检测的 L0 resolution，原文字不出现在入口响应里。不做身份资格判断。

缺少回答、跳过、other、prefer_not_say：返回 hidden。网页不请求日期列表，不显示身份标题、字段、录入提示或表单。真实日期已存在也不能替代 O2 答案；损坏证明及真实旧快照回滚均失败关闭。读取不做 recovery、adoption、分类或新默认答案，也不授予 C5 完成、模型、工具或执行权限。

准入撤回后本人仍能阅读与删除既有资料；新确认仍由原记录服务检查当前准入。会话失效、账号窗口不同、员工账号和跨用户访问沿用实际身份边界。

## 页面行为

一次编辑一项：日历日期、本人原话状态、明确的布尔答案、本人记的待业整数、本人报告的 H1B 年份与结果、自定义日期及标签。新记录不预填日期、年份、布尔值、0 或抽签结果。未回答保留空值；取消不建立记录。

保存后显示原日期，不把日历日转换成浏览器时区。待业数字默认折叠，打开后只显示上次本人记的数字及 UTC 记录日期。数值不随时间变化，不显示制度限额、剩余天数、资格、进度条或变色。字段敏感度由服务端固定；全部值只在本人网页管理中展示，不送模型、共享记忆、语音、Discord 或通知。

每张记录与页面带产品固定页脚：信息与提醒，不是法律意见。涉及你个人身份的决定，请先和学校 DSO 或移民律师确认。个人资料外壳保留 AI 标识，滚动时固定；手机列表单列、按钮至少 44px，使用现有纸色与墨色 token，无负面红色。

## 保存不确定与账号切换

网页请求客户端核对闭合响应、账号、原 nonce、动作、记录与版本，核对 fresh 回执中的实际值。回执投影新增 action，以便拒绝动作替换。

保存超时或响应丢失：保留原指令，显示“还在确认，先别关页面”，锁住新提交。本人可读取原操作结果或以同一 nonce 重试；观察时的 404 可与原事务竞态，不被当作失败或成功确认。迟到的旧 HTTP 响应不自行完成界面。

客户端、控制器与纯呈现场景分开。请求有读取/写入时限；账号撤销会取消请求，并同时清掉原指令、值、编辑稿。控制器重挂载用 generation 拦住旧请求回写。私人状态不进 localStorage、sessionStorage 或 Service Worker。

## 验证及尚待完成

真实 PostgreSQL / 密码登录 HTTP 覆盖原记录生命周期、结构选项、实际自由文字检测来源、原快照回滚、准入与会话、跨账号及旧记忆复核回归。网页协议与控制器测试覆盖丢响应、超时、观察竞态、原 nonce 重试及账号切换。实际 React 服务端渲染使用虚构数据，验证 hidden 场景没有字段或补填提示、无默认答案、折叠数字、HTML 转义、页脚和 AI 标识。渲染测试不读取用户资料，也不是浏览器视觉走查。

C5 按真实初见对话顺序录入/跳过、选定侧栏日期与隐藏偏好、今天/旅程的 StatusClock、专业审核后提醒、授权主理人使用仍需继续实现。当前没有 C5 完成/跳过记录，因此不从这个管理页或 O2 答案推导任何全局时钟展示，也不出自动提醒。

未更新主预览或主数据库，无付费模型调用、部署或 PR 合并。私人浏览器视觉走查尚未完成。

远端验证：40 项真实数据库／HTTP／网页客户端联调与回归、48 项契约测试、687 项网页测试通过，无失败或跳过；契约/API/Web 类型检查及网页构建通过。TypeScript 排版核对语法树完全一致，之后再次检查类型。未把这些定向结果当作全套 CI 或浏览器视觉走查通过。
