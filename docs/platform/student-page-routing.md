# 学生资料页面的路由分发

依据产品 05 §0.3、08 §7.13 和 09 第 4 步，将已有的学生资料页面从 `App.tsx` 拆到 `apps/web/src/app/StudentRoutes.tsx`，路由识别位于同目录 `student-route.ts`。现有 13 个精确页面入口（包含真人导师旧别名）与机构来源详情保持可访问，实际内容仍由各自领域 API 读取。

四类详情链接（待确认、故事、面试、投递）使用一致的 UUID 校验与小写规范化。无效 id、多余路径段和编码分隔符不再落回普通聊天，而是显示「这条内容不存在或已经处理」和对应列表入口。不在页面中回显原 URL 或记录信息。合法 UUID 的不存在或跨账号记录继续由原领域 API 判定，路由匹配不代表有权读取。

页面分发仍在账号、邮箱、协议、第一封信门槛之后。组件额外核对当前账号捕获与用户 id；按账号、捕获代次和路径挂载，避免后续路由切换复用另一条记录的局部状态。保留页面懒加载，未修改 API、数据表、后台任务或模型调用。

本次不是完整 History API router 或五栏外壳。未迁移路径仍交回现有 App；今天、对话列表、主线与单聊、面试间的路由和 UI 尚未完成，也没有把占位页面当作交付。后续需要按 05/08/09 接入真实服务与统一导航；主对话引擎的评测顺序门槛保持原状态。
