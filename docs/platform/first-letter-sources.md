# 第一封信的真实事实来源

依据产品 02 §5.4 和 05 §2.1 C7。FirstLetterSources 已由 buildApp 使用真实服务组装，供后续后台信件生成事务读取；当前先接已存在的 C1「直接写信吧」路径。该路径在产品中明确只引用 O2 信息。本来源服务没有生成信、保存信、完成 C7 或解锁学生页面。

## 真实触发与来源

在同一有界事务和本人锁内：

1. 核对真实会话、学生身份、当前邮箱/协议和已保存诞生；复用真实生成完成回执、诞生原始记录与完整问答操作前缀认证。
2. 解密、核对已诞生主理人当时的完整答案。CompanionBirthAnswerSources 是内部共享读取器；完整返回值含私有答案，禁止作为模型上下文、HTTP 响应或日志使用。原 CompanionPlanningSources 现在复用它，但仍只返回原有 Q4 小步偏好，字段和错误契约保持一致。
3. 核对实际欢迎记录、主线、诞生回执、固定 C1 消息及不可改写选择凭据；只有实际 C7/direct_letter 才返回本用途的快照。C1、C2、未打开欢迎段、客户端传来的事实或声称的完成状态都不能成为触发。
4. 调用实际初见/命名安全来源检查，再次核对会话和取消状态。历史诞生或已保存选择不能替代当前检查。这只覆盖现有初见/命名通道，不代表尚未接入的主对话安全分类或完整 overlays 已完成。

事实只白名单投影 study、graduation、roles、search_stage 四个 O2 问题的实际结构化答案；每条保存来源种类、答案记录 ID、原稿 ID、问题、应用版本与捕获版本。标记为 birth_o2 / user_entered / self_reported，不能当成已确认共享记忆、已核实工作经历或当前看板状态。roles=undecided 保持未定方向，不替用户选择。

每个问题最多算一条事实，专业和学制不会拆成两条凑数。跳过的题不生成事实，返回 omittedQuestions；零/一条分别要求引用实际零/一条，并标明 needsMoreFacts=true，供后续信件明确说明接下来要了解什么。两条及以上 requiredFactReferences=2；这不是模型已引用事实的证明，仍须检查实际生成输出与 source_ref。

情绪语言仅保留用户选定的 zh/en/either 或未选择的 null，不推断偏好。身份阶段与日期、自由输入原文、情绪原话、问卷情境题、原始安全分类、简历、共享记忆和未核实外部信息均不进入此快照。自由输入若已通过原流程正规解析成 O2 选项，读取的也只是已保存结构值，不是原文。

## 新鲜度与消费边界

快照和嵌套数据冻结；sourceId 基于实际投影和触发凭据计算，重复读取不随时钟改变。assertCurrentInTransaction 要求本人和原 sourceId，重新读取全部来源、触发与当前准入；异用户、额外字段、过期/错误摘要或损坏来源均拒绝。摘要不是签名、模型调用许可或跨事务授权。

未来生成器必须在自己的源准备、模型发送前和最终保存时重新核对相应真实状态，并绑定人格、费用、租约、输出与送达回执。本次没有把来源对象送给模型，也没有对客户端开放传入事实或触发完成的接口。原欢迎段继续明确显示信件生成尚在接入。
