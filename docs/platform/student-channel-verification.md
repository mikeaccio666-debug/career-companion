# 学生 HTTP、SSE 与网页接入验收

2026-10-06（美国太平洋时间），基于 `codex/student-model-routing` 的准备实现。产品边界仍以 [实施路线](../product/09-implementation-roadmap.md) 和 [语音规划](../product/12-voice.md) 为准。

## 本轮行为

默认网页只挂载对话、我的资料库和设置。普通聊天、实时会话和独立转写使用服务端配置的路由；浏览器不提交 provider/model。匿名启动读取布尔能力与 features，内部供应商详情需要真实会话、当前账号断言和显式开发配置。缺失或非法 features 不开启内部工作台。

学生响应采用明确的公共字段投影。工具 SSE 只含真实 messageId、名称与状态，不发送工具参数、结果、审批或用量事件；用户正文与资料原文保留。数据库中的实际供应商、用量、冻结分析与执行记录不被改写。普通学生聊天不会继承历史的用户自选 persona。

新通用任务、定义和首次启动受工作台开关限制。准入在新任务实际创建、重试或批准的事务边界内检查；已受理任务的 worker、取消、历史读取和已有计划绑定保持原语义。学生语音合成明确不可用，网页不挂载通用语音面板；现有 RTC/ASR 基础设施保留。原生 RTC 协议仍可能包含供应商端点和临时凭证，不能据此宣称网络层供应商隔离。

## 实际验证

- 固定 Node 24.21.0、pnpm 11.13.1。网页类型检查、生产构建通过，完整网页测试 **469/469**；纯路由、投影和 SSE 检查 **54/54**。
- 远端独立源码副本运行完整 platform-api 的 **65 个测试文件、614 项：610 通过、4 跳过、0 失败**。contracts、career-core、ai-core 和 API 类型检查通过。四个跳过项为两组可选真实 Chromium 执行、官方隔离 Codex broker、本地 S3；未将其计作通过。
- 新真实 PostgreSQL/HTTP 用例使用虚构账号、真实 cookie 与账号断言，覆盖服务端路由、历史 persona、私有持久数据与公共投影、新旧绑定、冻结分析、锁等待后的重试准入和语音字段限制。合成 transport 不代表模型质量或声音听感验收。
- 独立 Chrome 加载本轮生产构建与虚构 loopback API。桌面与 390×844 视口确认学生导航、原文显示、标题请求与消息 SSE、资料追加但不自动发送、非法 features 刷新后草稿保留，以及账号冲突后重新确认并清除旧私人草稿。手机视口无横向溢出；截图人工查看。这里不是手机真机、软键盘、麦克风、ASR 或 WebRTC 端到端验收。
- 浏览器请求没有隐藏工作台的任务、审批、计划、工具或供应商详情轮询。缓存中 API 条目为零；仅出现主动测试账号冲突 409、缺失 features 404 的两条网络 console error，未发现其他错误或警告。
- 独立审查完整读取全部 20 个旧 HTTP fixture 的改动，确认身份、归属、租约、取消、账务和冻结来源断言保留。所有测试与浏览器运行使用的源码均以文件 SHA 核对冻结版本。

测试数据库在所有者、零活动连接及零遗留 fixture schema 核验后删除；临时环境、独立源码与运行目录清理，私有证据保存在忽略目录。主源码、配置、迁移账本、已有服务与原开发预览保持不变。未调用付费模型、发送真实邮件、提交求职申请或部署。

## 尚未完成

本轮完成接入边界，不等于整个路线第 0 步或上线条件通过。专属主理人、真实专家身份和多人编排、职业验证旅程、面试房间、危机处理、语音披露与缓存、真实 staff 权限及上线门槛仍须按产品文档实现。生产构建仍有大分包警告，响应式布局通过不能证明移动加载性能。本人专业声线训练不属于当前产品语音阶段。
