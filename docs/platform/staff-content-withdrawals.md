# 运营下架记录列表

依据产品 04 §4.8 的 P0 运营只读列表。该功能显示已下架的组织来源，员工不能从这里恢复、编辑、发布或再次下架内容。

## 入口与权限

- 网页：`/staff/orgs/<组织 UUID>/content-withdrawals`。反馈收件箱在成功确认组织后提供入口。
- API：`GET /api/platform/staff/orgs/:id/content-withdrawals?after=<来源 UUID>`。
- 必须同时具备真实会话、账号上下文、邮箱门和该组织有效的 ops / org_admin 员工角色。URL 中的组织编号只选取范围，不授予权限。学生、内容编辑、内容审核者和其他组织员工不能读取。
- 读取通过 `StaffAccess` 完成，复用 `org_sources_viewed` 审计动作，以组织为 target，记录返回数量。角色锁、晚到会话失效和审计提交检查沿用现有机制；审计失败不返回页面。

## 数据范围

只读取当前 review_status=withdrawn 的真实 tombstone，每页最多 50 条，按来源 UUID 升序并提供游标。游标必须是同组织的实际下架来源。并发新增下架记录可能排在已读游标之前，重新读取会从头开始；列表不声明为固定快照。

返回当前保留的来源名称、来源编号、下架版本和时间。版本、状态与时间核对现有加密来源回执及最新不可变证明；标题是保留的展示元数据，不宣称它是可重建的历史正文。已清除的正文和结构化内容必须保持为空；不返回原文、授权文件、编辑/审核员工标识、操作理由或学生资料。

不新增数据库表、字段、索引或迁移；不改变既有删除/导出分类。

## 页面行为

网页沿用产品设计 token，提供空列表、读取中、分页、错误与重新读取。账号失效、页面隐藏或离线会清空可见内容并取消读取；晚到响应不能填回新账号或新一轮页面。重新获得权限需重新读取，不用缓存的列表冒充成功。反馈页和新列表共享认证/邮箱入口，不解除学生首封信与主对话门。

- contracts / API / Web 类型检查通过，Web 生产构建通过。
