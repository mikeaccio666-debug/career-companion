# 学生页面的统一导航外壳

依据 05 §0.3、08 §7.13 与 09 第 4 步，StudentRoutes 现在在账号核验后用 StudentShell 包住已经实现的学生资料页。此处属于可独立推进的界面外壳；App 的邮箱、协议、首封信准入仍在分发之前，privateAllowed 没有改动。

导航按“今天、对话、待确认、旅程、我”排序。手机与平板（小于 1024px）使用底栏，桌面使用顶部胶囊；嵌套的方向、岗位、故事和投递页选中“旅程”，共享记忆、资料、主理人设置与真人入口选中“我”。出处详情不冒充某个主栏目，错误详情保留原列表归属。没有读取或编造待确认计数。

当前没有可接入的学生对话列表和房间服务，所以“对话”明确为暂不可用，不导向旧工作台；宽屏常驻对话列表、房间头、指挥台和最终主理人印章仍待接入。本次不是完整五界面或 P0 完成。

## 页面与生命周期

外壳统一提供当前栏目、常驻 AI 身份提示、账号头像、退出、键盘跳到内容和主要导航。现有域页面通过上下文隐藏旧的页首导航，独立组件预览仍保留原导航；没有改动其请求客户端、写入协议或数据库。

仍使用原生链接，保留浏览器历史、刷新和各页面的 beforeunload 草稿保护，不引入绕过提示的全局 pushState 点击拦截。页面隐藏或离线时用 hidden/inert 收起内容，保持同账号组件实例以保留内存草稿；各领域控制器继续负责取消请求和重新读取。返回在线可见后再展示，账号失效则整个外壳及子页面卸载。没有新增私人持久缓存，也不承诺刷新或强制关闭后的草稿恢复。

手机输入框、选择框或可编辑内容聚焦时隐藏底栏；失焦后恢复。底栏含安全区预留，图标 24px、文字 12px、每项至少 44px 可点击，手机实际高度 56px。配色使用现有浅深色 token，顶部 AI 说明可换行。

## 验证

- Web 全量 893/893 通过，TypeScript 与生产构建通过；新加导航归属和固定路径检查。
- 真实 StudentRoutes、StudentShell、StudentMePage 和 SharedMemoryPage 配虚构账号/传输，在 Playwright 下核验原生页面跳转及嵌套栏目选中。
- 390×844、768×844、1440×900 无横向溢出；手机/平板底栏固定在底部，桌面导航位于顶栏。浅色手机和深色桌面截图已查看。
- 输入聚焦隐藏底栏；真实 browser offline/online 收起私人编辑、恢复原草稿；点击“旅程”出现原生 beforeunload，取消后保留原页；账号失效后外壳和编辑 DOM 均为零。
- 键盘“跳到页面内容”将焦点移到内容容器。浏览器用 emulated dark scheme 验证深色；不声称真实手机软键盘、设备安全区、系统大字或完整对话页面已经验收。
- 浏览器不连接真实业务后端；这些检查不能替代注册到第一封信、真实对话与数据写入的端到端验收。fixture 的 favicon 404 不涉及应用资产。

无 API、数据库、模型调用、主预览或部署变更。测试夹具、截图与日志留在忽略目录。
